# 小鲜菜 · 家庭食材库存管理

帮你管好家里冰箱里的食材，快到期提醒、菜谱缺料一键加入采购，减少浪费。

## 解决什么问题

- 冰箱里的菜买回来放着就忘了，等想起来已经过期
- 想做饭的时候不知道现有食材能做什么
- 缺料要再跑一趟超市，不知道该买什么
- 分不清"赏味期"（口感最好）和"保质期"（安全底线）

小鲜菜把这几件事收进一个手机端界面：录入食材 → 到期提醒 → 菜谱匹配 → 缺料进采购清单 → 买完打勾自动入库。

## 主要功能

### 库存首页
- 顶栏显示今天日期，一眼看到冰箱里有几样东西
- **快到期提醒**：赏味期 ≤2 天的食材自动进橙色提醒条
- **已过期分区**：红色卡片列出过期食材，支持"已处理"（删除）和"延长 3 天"
- 分类筛选：全部 / 蔬菜 / 水果 / 肉蛋 / 水产 / 粮油 / 乳制品
- 右下角悬浮按钮 `+` 添加新食材

### 添加食材
表单字段：图标（30 个 emoji 选一个）、名称、分类、数量+单位、保质期天数、赏味期天数、存放位置（冷藏/冷冻/常温）、热量标签（低/中/高，绿黄红三色）、预计花费。

### 菜谱页
- 6 道家常菜（番茄炒蛋、香煎鸡胸、牛油果沙拉、猕猴桃思慕雪、三文鱼刺身、菠菜蛋花汤）
- 自动按"现有食材匹配度"从高到低排序，进度条显示已有几样
- 点进去看食材清单和步骤；缺料可以一键"加入采购"或标记"已有"

### 采购清单
- 顶部显示预计花费和待采购数量
- 每项打勾后**自动入库**（按分类/数量/单位/保质期写进库存）
- "+ 添加新采购项"打开完整表单，不再是只输名字

### 统计页
- 4 个卡片：总食材、已过期、库存价值、高热量食材数
- 热量分布条（低/中/高）
- 分类占比行，**点任意分类**弹出该分类下的所有食材明细

### 我的
- 消息通知说明、热量阈值说明、数据存储说明、版本信息

## 安装方法

需要 Node.js 18+。

```bash
cd xiaoxiancai-web
npm install
```

## 使用方法

```bash
npm run dev
```

默认端口 28471，浏览器打开 http://localhost:28471/

其他命令：

```bash
npm run lint      # 类型检查 + ESLint
npm run build     # 生产构建到 dist/output
```

## 输入输出示例

### 录入一份食材

**输入**（在"添加食材"弹层里）：
```
名称：菠菜
图标：🥬
分类：蔬菜
数量：1 把
保质期：5 天
赏味期：2 天
存放位置：冷藏
热量标签：低
预计花费：¥5.8
```

**输出**（库存首页多一张卡片）：
```
🥬 菠菜  低热
蔬菜 · 冷藏 · 1把 · ¥5.8
0天后 赏味期
```

### 菜谱缺料加入采购

**输入**（点开"番茄炒蛋"）：
```
需要的食材：番茄（已有）、鸡蛋（已有）、葱（缺）
```

点"葱"那一行的「加入采购」→ 填数量 1 把、预计 ¥2，确认。

**输出**：
- 菜谱详情里葱那一行变成紫色标签「已加采购清单」
- 采购清单页多出一项「🥬 葱 1把 ¥2」，待采购数 +1，预计花费 +¥2

### 采购打勾自动入库

**输入**：在采购清单勾选「牛奶 1 盒 ¥12.5」

**输出**：
- 该项变灰、划线
- 库存首页新增一条「🥛 牛奶 中热 / 乳制品 · 冷藏 · 1盒 · ¥12.5」
- toast 提示「牛奶 已入库」

## 数据说明

- 所有数据存在浏览器 `localStorage`，key 前缀 `xiaoxiancai:`，不上传服务器
- 换浏览器或换设备数据不同步
- 首次打开内置 8 样示例食材、6 道菜谱、2 条采购项，可直接体验

React 19 + Vite + TypeScript + Tailwind CSS v4 + shadcn/ui + react-router-dom + lucide-react + sonner
